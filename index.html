The Problem & Solution

Core Value

Traditional learning apps allow users to passively watch videos or guess multiple-choice quizzes without proving genuine understanding.

ProofLoop changes this by forcing users to defend their solutions out loud. The multimodal AI evaluates reasoning depth, unlocks sequential skills through prerequisite verification, and mints cryptographically tamper-proof Proof Cards.

Key Innovations for Judges

Hackathon
  • 🛡️
    Zero-Config Offline Demo: Fallback AI ensures judges never get blocked by network or API key issues.
  • 🎙️
    Voice-First Defense: Verbal reasoning captures true mastery that automated unit tests miss.
  • 🔒
    Prerequisite Enforcing: Advanced algorithmic missions remain strictly locked until prerequisites are proved.
  • 📜
    Cryptographic Proof Cards: Verifiable skill credentials issued with SHA hashes and exportable cards.

fun binarySearch(arr: IntArray, target: Int): Int {
  var low = 0; var high = arr.size - 1
  while (low <= high) {
    // Safe midpoint avoids 32-bit overflow:
    val mid = low + (high - low) / 2
    if (arr[mid] == target) return mid
    else if (arr[mid] < target) low = mid + 1
    else high = mid - 1
  }
  return -1
}
